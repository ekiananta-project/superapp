Ubah PIN perangkat ini

Perubahan hanya berlaku pada Trusted Device ini. PIN perangkat lain tidak ikut berubah.

Kamu boleh memakai PIN yang sama seperti Trusted Device lain agar lebih mudah diingat. RuangKitha tetap menyimpan perlindungan PIN secara terpisah pada setiap perangkat.

Setelah PIN berubah, vault akan dikunci. Buka kembali memakai PIN baru.

Cabut Trusted Device

Perangkat ini tidak akan dapat membuka Security Vault lagi.

Setelah dicabut, Device Master Key envelope perangkat dinonaktifkan. Untuk memakai perangkat itu lagi, pulihkan sebagai Trusted Device baru menggunakan Recovery Kit.

PIN dipakai lokal untuk membuktikan kepemilikan Master Key. PIN tidak dikirim ke server.
